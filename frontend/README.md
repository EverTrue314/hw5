# Campus Customs Agent Dashboard

React, Vite, and TypeScript dashboard for the Homework 5 FastAPI backend.

Start the API from `backend/` with `../.venv/bin/uvicorn main:app --reload --port 8000`. In another terminal, from `frontend/`, run `npm run dev`. Open `http://localhost:5173`; the browser calls the API directly at `http://localhost:8000`. FastAPI allows the local Vite origins on ports 5173.
